# Security Policy

## Supported Versions

This repository currently supports security updates on the active development branch.

| Branch | Security Updates |
| --- | --- |
| `main` | Yes |

## Reporting a Vulnerability

Please do **not** open public issues for security vulnerabilities.

Use GitHub private vulnerability reporting instead:

- https://github.com/Mzx2003/cityvision/security/advisories/new

If private reporting is unavailable, open an issue with minimal details and request a secure contact channel.

## Response Targets

- Initial acknowledgement: within 3 business days
- Triage outcome: within 7 business days
- Remediation target: based on severity and impact
