# CityVision – Real-Time Traffic Violation Detection System

CityVision is a front-end demo showcasing a modern dashboard for traffic
violation detection. The UI is built with React, Vite, and Tailwind CSS and
uses mock data to simulate camera activity and enforcement workflows.

## Features

- Home, Dashboard, and Cameras pages
- Dark, modern UI styling
- Simulated detection feed with mock data
- Responsive layout optimized for desktop and tablet

## Getting Started

```bash
npm install
npm run dev
```

## Notes

This project is a UI-only demo (no backend). Data shown in the dashboard and
cameras pages is mocked for presentation.
